# 更新紀錄

## v0.9.2-beta（2026-10-10）

- 快捷圖示列（遊戲選項「Quick action icons (快捷圖示列)」，預設開啟）：滑鼠移到右下角時出現，可直接開背包、屬性頁、地圖、選單，切換戰鬥模式，使用鑰匙圈、召回石、睡袋，以及存檔、讀檔。
- 台詞框可調整：每頁行數 `bark_lines`（高解析開啟時預設 4 行）、寬度 `bark_width`。
- 新增設定說明 `SETTINGS.zh-TW.md`；`scummvm.ini` 的每個設定都加上中文註解。

## v0.9.1-beta（2026-10-10）

- 高解析中文字（遊戲選項「High-resolution Chinese text (高解析中文字)」，預設開啟）：中文以視窗解析度繪製，字型 jf open 粉圓；遊戲畫面本身不變。片頭字幕、對話、選項、書、選單都適用。
- 屬性頁（STR、INT…）在高解析中文字開啟時顯示中文：力量、智力、敏捷、護甲、生命、魔力、負重。
- 修正 ScummVM 原有的 bug：跳躍時撞到牆或障礙物，主角會卡住不動（遊戲像停住），或穿出地圖。

## v0.9.0-beta（2026-10-09）

第一個公開測試版。

- 全遊戲中文化：對話、選項、物品名稱、書與捲軸、墓碑與牌匾、片頭字幕（6,949 / 7,000 條，以英文字元計 99.8%）。
- 專有名詞第一次出現時附英文，可在遊戲選項關閉。
- ScummVM 遊戲選項：「Traditional Chinese translation (繁體中文)」開關（預設開啟）。
- 中文字型 Cubic 11；可換字型，並可調整字距、中英文間距、行距（`scummvm.ini`）。
- 存檔與英文版完全相容。

已知問題見 `README.zh-TW.md`。
