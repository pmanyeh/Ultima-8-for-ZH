# 更新紀錄

## v1.0.3（未發布）

- **高解析度預設開啟**：遊戲以 640×400 執行，看得到的範圍更大。背包、台詞框等介面會變小，可在遊戲設定取消勾選「高解析度」改回原版的 320×200。
- **攻擊滑鼠所指的對象**：戰鬥中雙擊攻擊或踢腿時，聖者會轉向滑鼠所指的敵人並立刻出手。原版的方向以畫面中央為準，常常差一格而揮空；沒有面向那個方向時，雙擊只會轉身，要再點一次才會攻擊。
- **傷害數字顯示所有人**：畫面上任何人受傷都會顯示（包含魔法、陷阱、摔落）；聖者受傷為橘黃色。聖者沒打中時顯示「揮空」。
- **血條**：人物被攻擊後，頭上顯示剩餘生命值的血條約 4 秒。
- 以上都可以在中文設定的【操作】區塊關閉，見 `SETTINGS.zh-TW.md`。
- 修正聖者撞到屍體等物件時，遊戲偶爾卡死的問題（原版也有）。

## v1.0.2（未發布）

- **修正 macOS 版無法執行**：v1.0.0、v1.0.1 的 macOS 版沒有編入 Ultima 8 引擎（出現「Game id not supported」），也缺少 SDL3（一開啟就結束）。感謝 IsleFan 找出原因並修正。
- macOS 版改為自行編譯 SDL2 與 FreeType，不再依賴 Homebrew：Apple Silicon 版支援 macOS 11 以上，Intel 版支援 macOS 13 以上（感謝 IsleFan）。macOS 版沒有 FluidSynth，SoundFont 改由 macOS 內建音源載入，見 `INSTALL-macOS.zh-TW.md`。
- 譯名改依 1993 年軟體世界中文版手冊：魔法學派（降靈術、役水術、神通術、奇術）、元素泰坦（里索斯、海特蘿、史卓拉透絲）、人物與地名（泰納布利、莫迪雅、摩蓋林等）、稱號、法術名與藥材。遊戲標題沿用《創世紀 VIII：異教徒》，遊戲中的世界名稱仍是「佩根」。
- 女性角色的譯名改用女性化的字：珂林絲、洛西安、綺蘭朵、翠西安、艾莉兒。
- 對話時點畫面任何地方都會翻頁，和 Ultima VII 相同（原版要點在文字上）。
- Esc 先關閉最上層的箱子、背包、袋子、屬性頁，全部關完再按才打開選單。
- 這兩項都可以在中文設定或 `scummvm.ini` 改回原版行為，見 `SETTINGS.zh-TW.md`。
- **中文設定頁**：遊戲設定的「遊戲」分頁新增字型、字級、字距、行距、台詞框、操作方式的設定（下拉選單與滑桿），不用再手改 `scummvm.ini`；遊戲中修改，回到遊戲就生效。
- **ScummVM 介面改為正體中文**（由 ScummVM 的簡體中文翻譯轉換而來）。
- **輔助跳躍**：開啟「跳向滑鼠位置」時，聖者會整個人落在滑鼠所指的石頭或平台中央，不再落在邊緣滑進水裡；落點被岩石、植物擋住時改落在附近的空位，放不下才搖頭。站著不動、滑鼠指向目標、按空白鍵起跳。
- **傷害數字**：聖者打中敵人時，敵人頭上浮出紅色的傷害數字；被盔甲完全擋下時顯示「格擋」。
- **藥水依效果命名**：治療藥水、法力藥水、輕度治療藥水、毒藥、無敵藥水、沉睡藥水、隱形藥水（原版都叫「藥水」，要靠顏色記）。

## v1.0.1（2026-10-11）

- 修正自動走近使用：雙擊樓上桌上的書等物品時，聖者有時會走到樓下的相同位置，或在原地搖頭。現在會走到真正拿得到物品的位置再使用。
- 新增主控台指令說明 `CONSOLE.zh-TW.md`：傳送、作弊、播放動畫與音樂等指令的用途與用法。
- `SETTINGS.zh-TW.md` 新增「音樂音源」一節：General MIDI、FluidSynth、AdLib、Roland MT-32 的設定方式，以及 MT-32 ROM 的放置位置。
- 說明文件更新：移除已修正的已知問題（巫師門徒自我介紹時的名字），macOS 版的安裝說明另見 `INSTALL-macOS.zh-TW.md`。

## v1.0.0（2026-10-11）

第一個正式版。

- 新增 macOS 版：Apple Silicon（arm64）與 Intel（x86_64）各一包，由 GitHub Actions 自動建置，安裝方式見 `INSTALL-macOS.zh-TW.md`。功能、翻譯、字型與 Windows 版相同。

## v0.9.3-beta（2026-10-10）

- 墓碑牌匾全中文（遊戲設定的「墓碑牌匾全中文」，預設開啟）：墓碑、牌匾與死亡畫面直接刻上中文，使用王漢宗魏碑體與雕刻陰影效果。
- 書本、捲軸、片頭字幕、墓碑、牌匾可以各自設定字型、字級、顏色、間距與雕刻陰影（`font_cjk_<類別>_*`，見 `SETTINGS.zh-TW.md`）。
- 補上最後的翻譯缺口：巫師門徒自我介紹時的名字。
- 自動走近使用（遊戲設定的「自動走近使用」，預設開啟）：雙擊太遠的門、箱子、書等物品時，聖者會自動走過去再使用。

## v0.9.2-beta（2026-10-10）

- 快捷圖示列（遊戲選項「Quick action icons (快捷圖示列)」，預設開啟）：滑鼠移到右下角時出現，可直接開背包、屬性頁、地圖、選單，切換戰鬥模式，使用鑰匙圈、召回石、睡袋，以及存檔、讀檔。
- 台詞框可調整：每頁行數 `bark_lines`（高解析開啟時預設 4 行）、寬度 `bark_width`。
- 作弊圖示組（勾選「開啟作弊」時出現在左下角）：屬性全滿、體力恢復、無敵模式、神力模式（可搬動任何物品）。
- 修正 ScummVM 原有的 bug：在遊戲選項按下確定時，偶爾會因字型快取錯誤而當掉。
- 新增設定說明 `SETTINGS.zh-TW.md`；`scummvm.ini` 的每個設定都加上中文註解。

## v0.9.1-beta（2026-10-10）

- 高解析中文字（遊戲選項「High-resolution Chinese text (高解析中文字)」，預設開啟）：中文以視窗解析度繪製，字型 jf open 粉圓；遊戲畫面本身不變。片頭字幕、對話、選項、書、選單都適用。
- 屬性頁（STR、INT…）在高解析中文字開啟時顯示中文：力量、智力、敏捷、護甲、生命、魔力、負重。
- 修正 ScummVM 原有的 bug：跳躍時撞到牆或障礙物，主角會卡住不動（遊戲像停住），或穿出地圖。
