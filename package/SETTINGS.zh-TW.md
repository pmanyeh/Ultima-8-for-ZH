# 設定說明

本中文版的設定分成兩種：

- **遊戲設定**：在 ScummVM 介面裡調整。最上方是開關（勾選框），往下捲動是**中文設定**：字型、字級、字距、台詞框、操作方式，用下拉選單和滑桿調整。
- **`scummvm.ini`**：介面沒有的細部調整（例如文字顏色、雕刻陰影），用文字編輯器修改。

## 一、遊戲設定（勾選框）

在 ScummVM 選取遊戲，按「遊戲設定」（Game Options…）→「遊戲」分頁：

| 選項 | 預設 | 說明 |
|---|---|---|
| 繁體中文翻譯 | 開 | 中文化開關。取消勾選就是原版英文 |
| 名稱加註英文 | 開 | 人名、地名等專有名詞第一次出現時附上英文，例如「戴文(Devon)」 |
| 高解析中文字 | 開 | 中文以視窗解析度、jf open 粉圓字型繪製，清晰易讀；遊戲畫面本身不變。**重新啟動遊戲後生效** |
| 自動走近使用 | 開 | 雙擊太遠的門、箱子、書等物品時，聖者會自動走過去再使用；走不到時會搖頭。途中自己移動、戰鬥或對話就會取消 |
| 墓碑牌匾全中文 | 開 | 墓碑與牌匾直接刻上中文（王漢宗魏碑體，雕刻效果）。關閉時為英文雕刻加中文字幕 |
| 快捷圖示列 | 開 | 滑鼠移到畫面右下角時出現的快捷圖示（背包、屬性、戰鬥、地圖、選單、鑰匙圈、召回石、睡袋、存檔、讀檔） |
| 高解析度 | 開 | ScummVM 原有的選項：遊戲以 640×400 執行，看得到的範圍比原版 320×200 大。背包、台詞框等介面會變成原本的一半大；覺得太小可以取消勾選。**重新啟動遊戲後生效** |

這些勾選框在 `scummvm.ini` 的 `[ultima8]` 區段裡依序是 `localization_zh_tw`、`localization_annotate`、`hd_text`、`walk_to_use`、`engraving_chinese`、`quick_bar`、`usehighres`（`true` 為開、`false` 為關）。平常在介面切換即可；macOS 版或想直接改設定檔時，可以用這些名稱。

### 中文設定

同一個「遊戲」分頁往下捲動，就是中文設定。按「確定」儲存；在遊戲中（Esc →「4.選項」）修改時，回到遊戲就會生效，不用重新啟動。每個項目對應下面幾節的 `scummvm.ini` 設定：

| 區塊 | 項目 | 對應設定 |
|---|---|---|
| 對話文字（高解析） | 字型、字級、字距、中英間距、行距、黑框 | `font_cjk_hd_*`（第四節） |
| 對話文字（點陣） | 字型、字級、字距、中英間距、行距 | `font_cjk_*`（第三節） |
| 台詞框 | 每頁行數、寬度 | `bark_lines`、`bark_width`（第五節） |
| 書本與捲軸 | 字型、字級、字距 | `font_cjk_book_*`、`font_cjk_scroll_*`（第七節，兩者一起設定） |
| 墓碑與牌匾 | 字型、字級、字距 | `font_cjk_grave_*`、`font_cjk_plaque_*`（第七節，兩者一起設定） |
| 操作 | 對話時點任何地方翻頁、Esc 先關最上層視窗、跳向滑鼠位置時落在目標中央、攻擊滑鼠所指的對象、顯示傷害數字、顯示被攻擊者的血條、快捷圖示列只在滑鼠移過去時出現 | `bark_click_anywhere`、`esc_closes_gumps`、`assisted_jump`、`attack_target`、`damage_numbers`、`health_bars`、`quick_bar_autohide`（第六、十節） |

- 字型清單會列出 `extra` 資料夾與遊戲資料夾裡的 `.ttf`、`.otf`；把字型檔放進 `extra`，下次打開設定就會出現。
- 「恢復預設」把中文設定恢復成預設值（不含上方的勾選框），按「確定」後生效。
- 只有和預設不同的值才會寫進 `scummvm.ini` 的 `[ultima8]` 區段。

## 二、修改 `scummvm.ini`

`scummvm.ini` 在本包的資料夾裡（和 `scummvm.exe` 同一處）。

1. **先關閉 ScummVM**。ScummVM 結束時會寫回這個檔案，開著修改的話，你的修改可能被蓋掉。
2. 用記事本等文字編輯器開啟，存檔時請用 **UTF-8** 編碼。
3. 以 `#` 開頭的行是註解。每個設定前都有一行中文註解，說明它屬於哪一類、做什麼用。ScummVM 會保留這些註解，但存檔時會重新排列設定的順序，所以設定不一定照分類排在一起。
4. 預設沒有寫出來的設定（例如 `font_cjk_hd_size`、`bark_lines`），列在檔案開頭的說明裡。需要時，把 `設定=值` 這一行加到 `[scummvm]` 區段即可。
5. 寫在 `[scummvm]` 區段的設定對所有遊戲有效。如果只想改 Ultima VIII，可以寫在 `[ultima8]` 區段（新增遊戲後才會出現）；兩邊都有時，以 `[ultima8]` 為準。

> 數值後面不要加註解（例如 `bark_lines=4 # 四行`），註解請寫成獨立的一行。

## 三、中文字型（未開高解析時）

遊戲原本的畫面是 320×200。未開高解析中文字時，中文字直接畫在這個解析度上，單位是像素。

| 設定 | 預設 | 說明 |
|---|---|---|
| `font_cjk_file` | `Cubic_11.ttf` | 字型檔，放在 `extra` 資料夾 |
| `font_cjk_size` | `12` | 字級 |
| `font_cjk_antialiasing` | `false` | 反鋸齒。點陣字型請關閉；一般向量字型建議開啟 |
| `font_cjk_letter_spacing` | `1` | 字與字之間多加的間距 |
| `font_cjk_latin_spacing` | `3` | 中文與英文字母、數字相接處再多加的間距 |
| `font_cjk_line_spacing` | `0` | 行與行之間多加的間距 |

開啟高解析中文字時，對話、選項、書等文字改用下一節的設定；這一節的字型仍用在少數維持原解析度的地方（例如製作人員名單）。

## 四、高解析中文字

遊戲設定的「高解析中文字」開啟時使用。數值的單位是**遊戲像素**（畫面寬 320），可以有小數，例如 `0.3`；引擎會依視窗大小自動換算，所以換視窗大小不用重調。

| 設定 | 預設 | 說明 |
|---|---|---|
| `font_cjk_hd_file` | `jf-openhuninn-2.1.ttf` | 字型檔，放在 `extra` 資料夾。建議用向量字型 |
| `font_cjk_hd_size` | 同 `font_cjk_size`（12） | 字級 |
| `font_cjk_hd_letter_spacing` | `0.3` | 字與字之間多加的間距 |
| `font_cjk_hd_latin_spacing` | `1` | 中文與英文字母、數字相接處再多加的間距 |
| `font_cjk_hd_line_spacing` | `0` | 行與行之間多加的間距 |
| `font_cjk_hd_border` | 原本黑框的一半（`0.5`） | 文字黑框的粗細；`0` 為無黑框 |
| `font_cjk_hd_antialiasing` | `true` | 反鋸齒 |
| `hd_text_size` | 配合視窗 | 高解析畫面的大小，例如 `1920x1440`。通常不需要設定 |

- 高解析畫面的大小在**遊戲啟動時**依視窗決定。遊戲中改變視窗大小也能玩，只是文字會跟著縮放；重新啟動遊戲就會重新配合。
- 屬性頁（STR、INT…）只有在高解析中文字開啟時才顯示中文，因為原解析度放不下中文字。

## 五、台詞框

人物說話時頭上出現的文字框。只影響中文台詞，英文台詞維持原版大小。

| 設定 | 預設 | 說明 |
|---|---|---|
| `bark_lines` | 高解析開啟時 `4`；未開時維持原版高度（約 3 行） | 每頁行數。框的高度依字型、字級、行距自動計算，最高約半個畫面 |
| `bark_width` | `194` | 寬度（遊戲像素，畫面寬 320），最大 `300`。寬一點換行就少一點 |

- 台詞框不會超出畫面：說話的人在畫面邊緣時，框會自動往內移。
- 每頁顯示的時間依該頁字數計算，一頁的字變多，停留時間也會跟著變長。
- 存檔裡記錄的仍是原版的台詞框大小，存檔與英文版相容。

## 六、快捷圖示列

| 設定 | 預設 | 說明 |
|---|---|---|
| `quick_bar_autohide` | `true` | `true`：滑鼠移到右下角才出現；`false`：一直顯示 |

開關本身是遊戲設定的「快捷圖示列」。滑鼠停在圖示上會顯示名稱與對應按鍵；圖示的功能和按鍵完全相同。體力／法力條（在屬性頁按小按鈕打開）開著時，圖示列會排在它左邊。

## 七、書本、捲軸、片頭字幕、墓碑、牌匾的字型

這五類文字可以各自設定字型，設定名稱是 `font_cjk_<類別>_<項目>`，類別為 `book`（書本）、`scroll`（捲軸）、`intro`（片頭字幕）、`grave`（墓碑，含死亡畫面）、`plaque`（牌匾）。數值的單位是遊戲像素，開啟高解析中文字時會自動放大。

| 項目 | 說明 |
|---|---|
| `_file` | 字型檔（`extra` 資料夾） |
| `_size` | 字級 |
| `_color` | 文字顏色，RRGGBB，例如 `404040` |
| `_antialiasing` | 反鋸齒 |
| `_letter_spacing`、`_latin_spacing`、`_line_spacing` | 字距、中英文間距、行距 |
| `_border` | 黑框粗細，`0` 為無黑框 |
| `_shadow_color` | 雕刻陰影的顏色，`none` 為不要陰影 |
| `_shadow_x`、`_shadow_y` | 陰影的偏移，可以是負數（例如 `-1` 表示往左上） |

沒有設定的項目沿用對話的設定（第三、四節）。墓碑和牌匾另有預設的雕刻效果：

| | 字型 | 字級 | 文字顏色 | 陰影 |
|---|---|---|---|---|
| 墓碑 | 王漢宗魏碑體 | 32 | 深灰 `404040` | 淺灰 `AEAEAE`，右下 1 像素 |
| 牌匾 | 王漢宗魏碑體 | 32 | 深褐 `6A4A1C` | 金色 `FFDB61`，右下 1 像素 |

例如讓書本的字大一點、墓碑的字再大一些：

```ini
font_cjk_book_size=13
font_cjk_grave_size=24
```

墓碑與牌匾要顯示中文，需開啟遊戲設定的「墓碑牌匾全中文」（預設開啟）；關閉時是英文雕刻加中文字幕。

## 八、作弊圖示組

在遊戲選項勾選「開啟作弊」時，畫面**左下角**會多一組作弊圖示，顯示方式和快捷圖示列相同（滑鼠移過去才出現；`quick_bar_autohide=false` 時常駐）：

| 圖示 | 功能 |
|---|---|
| 金色箭頭 | 屬性全滿：力量、敏捷、智力 25，體力、法力全滿 |
| 紅色藥水 | 體力恢復：體力、法力補滿 |
| 圓盾 | 無敵模式（切換） |
| 手 | 神力模式：可搬動任何物品（切換） |

切換類的功能開啟時，圖示底色會變紅。功能和 ScummVM 主控台的 `Cheat::` 指令相同。取消勾選「開啟作弊」，圖示組就會消失。

## 九、音樂音源

Ultima VIII 的音樂是 MIDI，可以選擇用哪一種音源播放。語音與音效是錄好的聲音，不受影響。

| 音源 | 需要準備 | 說明 |
|---|---|---|
| General MIDI（預設） | 不用 | 原版音樂是為 General MIDI 寫的。Windows 用內建的「Microsoft GS Wavetable Synth」，macOS 用系統內建的音源 |
| FluidSynth | SoundFont（`.sf2`） | 也是 General MIDI，但用你選的 SoundFont 播放，音色依 SoundFont 而定。網路上有許多免費的 SoundFont，例如 GeneralUser GS |
| AdLib | 不用 | 模擬早年 Sound Blaster 音效卡的 FM 合成音色，使用遊戲本身的 FM 音色資料，是 DOS 時代的原味 |
| Roland MT-32 | MT-32 的 ROM | 模擬 Roland MT-32 音源器。遊戲沒有為 MT-32 另做音樂，是把 General MIDI 的音樂轉到 MT-32 上播放 |

### 在介面設定

在 ScummVM 選取遊戲，按「遊戲設定」（Game Options…）：

1. 「音訊」分頁：勾選「覆寫全域音訊設定」，在「偏好裝置」選擇音源（`Windows MIDI`、`FluidSynth`、`AdLib emulator`、`MT-32 emulator` 等）。
2. 用 FluidSynth 時：「MIDI」分頁勾選「覆寫全域 MIDI 設定」，在「SoundFont」選擇 `.sf2` 檔。

### 在 `scummvm.ini` 設定

寫在 `[ultima8]` 區段：

```ini
# 音源：auto（自動，預設）、windows、fluidsynth、adlib、mt32；macOS 內建音源為 core
music_driver=fluidsynth
# FluidSynth 用的 SoundFont（完整路徑）
soundfont=D:\SoundFonts\GeneralUser GS.sf2
```

### Roland MT-32 的 ROM

MT-32 模擬器需要原機的 ROM。ROM 有版權，**本包與 ScummVM 都不附**，請使用你自己合法取得的檔案：

- `MT32_CONTROL.ROM` 和 `MT32_PCM.ROM`（MT-32），或
- `CM32L_CONTROL.ROM` 和 `CM32L_PCM.ROM`（CM-32L，有的話會優先使用）

檔名須完全相同。把這兩個檔案放進本包的 **`extra` 資料夾**（和字型、翻譯檔同一處），再把音源設成 `MT-32 emulator`（或 `music_driver=mt32`）即可。macOS 版放進 `ScummVM.app/Contents/Resources/`（和換字型的位置相同）。

- 選了 FluidSynth 卻沒有指定 SoundFont 時，遊戲可能停在啟動畫面；請先指定 SoundFont，或改回其他音源。
- 選了 MT-32 卻找不到 ROM 時，ScummVM 會顯示錯誤訊息，請檢查檔名與位置。

## 十、對話翻頁與 Esc 鍵

| 設定 | 預設 | 說明 |
|---|---|---|
| `bark_click_anywhere` | `true` | 對話或劇情演出時（聖者不能行動），點畫面任何地方都會翻到最上層那句話的下一頁，和 Ultima VII 相同。`false`：要點在文字上才會翻頁（原版） |
| `esc_closes_gumps` | `true` | 有箱子、背包、袋子、屬性頁開著時，Esc 會先關閉最上層的那一個，全部關完再按才打開選單。`false`：Esc 直接打開選單（原版） |

平常自由行動時，點地圖仍然是移動與查看，不受第一個設定影響。這兩項在中文設定的【操作】區塊裡切換，也可以寫在 `scummvm.ini` 的 `[ultima8]` 區段。

### 輔助跳躍與戰鬥輔助

| 設定 | 預設 | 說明 |
|---|---|---|
| `assisted_jump` | `true` | 開啟遊戲設定的「跳向滑鼠位置」時才有作用：站著不動、滑鼠指向石頭或平台、按空白鍵（或左右鍵同時按），聖者會整個人落在目標中央；落點被擋住時改落在附近的空位，放不下或太遠就搖頭。`false`：原版的落點 |
| `attack_target` | `true` | 戰鬥模式中雙擊左鍵（攻擊）或右鍵（踢）時，如果滑鼠指著人物或怪物，聖者會轉向他並立刻出手；指著空地則朝滑鼠方向出手。`false`：原版（方向以畫面中央為準，沒有面向該方向時這次雙擊只會轉身） |
| `damage_numbers` | `true` | 畫面上任何人受傷時（近戰、魔法、陷阱、摔落），頭上浮出傷害數字：其他人紅色、聖者橘黃色；被盔甲完全擋下時顯示「格擋」；聖者揮擊沒打中任何東西時顯示灰色的「揮空」。字型、大小、顏色可用 `font_cjk_damage_*`（其他人）、`font_cjk_damage_avatar_*`（聖者）、`font_cjk_damage_miss_*`（揮空）調整（寫法同第七節，預設 12 像素） |
| `health_bars` | `true` | 人物被攻擊後，頭上顯示剩餘生命值的血條約 4 秒，再被打中就重新計時；綠色（一半以上）、黃色、紅色（四分之一以下）。聖者不顯示（看屬性頁） |

注意：有些踏腳石會定時沉入水中再浮起（原版的機關），要趁石頭浮起時跳上去，並盡快跳往下一塊。

## 十一、常見的調整範例

**字大一點，每頁仍是 4 行**（台詞框會跟著變高）：

```ini
font_cjk_hd_size=14
bark_lines=4
```

**台詞框寬一點**：

```ini
bark_width=240
```

**換成自己的字型**（例如你電腦裡的其他中文字型）：把字型檔複製到 `extra` 資料夾，再設定：

```ini
font_cjk_hd_file=你的字型.ttf
```

字型必須是 TrueType（`.ttf`）或 OpenType（`.otf`）。如果有字顯示成方塊，表示該字型缺字，請換回 `jf-openhuninn-2.1.ttf`。請注意，Windows 內附的字型（例如細明體）只能自己使用，不能隨本包散布。

**想要原作風格的點陣字**：關閉遊戲設定的「高解析中文字」，就會使用第三節的 Cubic 11 點陣字型。

## 十二、還原預設

刪除你改過或加上的那一行，該設定就會回到預設值。想全部還原，可以從原本的壓縮檔取出 `scummvm.ini` 覆蓋；不過這也會清掉 ScummVM 記錄的遊戲清單，需要重新「新增遊戲」（Add Game…）。存檔不受影響。
