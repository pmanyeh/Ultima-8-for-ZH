# 創世紀 VIII：異教徒 繁體中文版 v1.0.3

讓 1994 年 Origin 的經典 RPG《Ultima VIII: Pagan》以**正體中文**遊玩。這是第一個公開發布的版本，Windows 與 macOS（Apple Silicon、Intel）都有免安裝版本。

本專案不是改寫遊戲檔案的漢化補丁，而是在開源的 [ScummVM](https://www.scummvm.org/) Ultima VIII 引擎裡加入中文化功能：**遊戲本身的資料一個位元組都不改**，遊戲邏輯、對話分支、語音、存檔全部照原版運作，只在畫面顯示時換成中文。除了完整翻譯，我們也為中文閱讀和現代玩家的習慣，加了不少原版沒有的輔助功能。

## 下載

| 檔案 | 適用 |
|---|---|
| `Ultima8-zhTW-1.0.3.zip` | Windows 10 / 11（64 位元） |
| `Ultima8-zhTW-1.0.3-macOS-arm64.zip` | macOS 11 以上，Apple Silicon（M 系列晶片） |
| `Ultima8-zhTW-1.0.3-macOS-x86_64.zip` | macOS 13 以上，Intel |

**需要你自己的正版 Ultima VIII 英文版遊戲資料**（例如 GOG 的 *Ultima 8 Gold Edition*）。本包**不含**任何遊戲資料、音樂或語音。

解壓縮 → 執行 `scummvm.exe`（macOS 是 `ScummVM.app`）→「新增遊戲」選擇遊戲的英文資料夾（GOG 版是 `Ultima 8\ENGLISH`）→ 啟動。詳細步驟見壓縮檔內的 `INSTALL.zh-TW.md` / `INSTALL-macOS.zh-TW.md`。macOS 第一次開啟請在 `ScummVM.app` 上按右鍵 →「打開」。

## 完整中文化

- **全遊戲翻譯**：NPC 台詞、對話選項、書籍、捲軸、墓碑、牌匾、主選單、日記、片頭字幕，共約 7,000 條（99.8%；沒翻的只有數字、密碼這類刻意保留的內容）。
- **對話選項可以直接點中文**，會走原本的對話分支；含玩家名字、數量、物品種類的句子（例如「50 堆木材」「發火術魔杖（剩 3 次）」）也能正確翻譯。
- **譯名參考 1993 年軟體世界中文版手冊**：魔法學派、元素泰坦、人物、地名、法術、藥材沿用手冊的譯法，熟悉當年中文版的玩家會覺得親切。全遊戲約 760 個專有名詞統一由譯名表管理，前後一致。
- **語音配中文字幕**：有語音的角色播放英文原音，配上中文字幕，翻頁與語音同步。

## 為中文閱讀設計的顯示

- **高解析中文字**：遊戲畫面維持原作的像素風格，中文則以視窗解析度、[jf open 粉圓](https://justfont.com/huninn/)字型繪製，放大全螢幕也清晰易讀。
- **專有名詞自動加註英文**：同一段對話中第一次出現的人名、地名會顯示「中文(English)」，方便對照原版與攻略，之後只顯示中文。
- **墓碑與牌匾刻上中文**：以王漢宗魏碑體加上雕刻陰影，看起來像刻在石頭上；也可以改回英文雕刻加中文字幕。
- **屬性頁、主選單、日記、離開確認也是中文**。

## 遊玩輔助（原版沒有）

這些功能都預設開啟，不喜歡的可以在遊戲設定的中文設定頁個別關閉，回到原版行為。

### 戰鬥：攻擊點到的敵人、傷害數字、血條
- **攻擊滑鼠所指的對象**：原版的攻擊方向是從畫面中央算起，敵人在斜方時常常揮空，沒面向敵人時雙擊還只會轉身。現在戰鬥中雙擊敵人，聖者會直接轉向他並出手。
- **傷害數字**：任何人受傷時頭上浮出數字（聖者受傷是橘黃色），被盔甲擋下顯示「格擋」，沒打中顯示「揮空」。魔法、陷阱、摔落的傷害也會顯示。
- **敵人血條**：被打中的敵人頭上出現血條，綠、黃、紅一眼看出還剩多少。

> 📷 **[圖 6：戰鬥]** 敵人頭上有血條與紅色傷害數字的畫面

### 跳躍、走路與操作
- **輔助跳躍**：開啟「跳向滑鼠位置」時，聖者會整個人落在滑鼠所指的石頭或平台中央，不再落在邊緣滑進水裡。水上踏腳石不再是惡夢。
- **自動走近使用**：雙擊太遠的門、箱子、書，聖者會自己走過去再使用。
- **快捷圖示列**：滑鼠移到右下角就出現（仿 Exult），一鍵開背包、屬性、地圖、選單、存讀檔、切換戰鬥、使用鑰匙圈與召回石。
- **對話點任何地方都能翻頁**（同 Ultima VII）；**Esc 先關最上層的背包或箱子**，全部關完才打開選單。
- **藥水依效果命名**：原版各色藥水都叫「藥水」要靠顏色記，現在查看時會顯示「治療藥水」「法力藥水」「隱形藥水」等。

> 📷 **[圖 7：快捷圖示列]** 滑鼠移到右下角、圖示列出現的畫面（可以順便打開背包）

### 畫面
- **高解析度預設開啟**：遊戲以 640×400 執行，看得到的範圍比原版大得多。背包等介面會變小，可在遊戲設定取消勾選「高解析度」改回原版的 320×200。

## 中文的設定介面

- **ScummVM 介面是正體中文**。
- **中文設定頁**：字型、字級、字距、行距、台詞框大小、上面這些輔助功能的開關，都用下拉選單與滑桿調整，遊戲中修改，回到遊戲就生效，不用手改設定檔。

> 📷 **[圖 8：中文設定頁]** 遊戲設定 →「遊戲」分頁往下捲的中文設定

## 已知事項

- 高解析度模式下，背包、台詞框等介面只有原本的一半大（之後會研究放大）。
- 存檔只存英文原文（所以中英文存檔可互換）；讀檔後，存檔當下正在顯示的那一句台詞或那組選項會是英文，下一句起就是中文。
- 製作人員名單與開發者語錄維持原文；結局動畫原本就沒有字幕。
