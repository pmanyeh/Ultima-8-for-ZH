# Phase P16 Report — Quick Action Icons（快捷圖示列）

## Result

**PASS**（2026-10-10 使用者試玩：「這樣玩起來方便多了」）

## 目標

效法 Exult 的圖示列，讓常用的鍵盤快捷功能可以用滑鼠執行。

## 使用者的決定（2026-10-10）

| 項目 | 決定 |
|---|---|
| 位置與顯示 | 右下角；平常隱藏，滑鼠移到右下角才出現 |
| 與體力/法力條 | 獨立元件；體力/法力條（`MiniStatsGump`）打開時排在它左邊 |
| 美術 | 借用遊戲裡的物品圖，找不到的自己畫 |
| 提示 | 要，中文 |
| 開關 | 遊戲選項勾選框，預設開啟 |

## Environment

- Engine: `scummvm-src/` 分支 `ultima8-zh-tw-dev`：`297c58229b`
- 新檔：`gumps/quick_bar_gump.h/.cpp`；`ultima8.cpp`（建立時機、選項切換）、`metaengine.cpp` / `detection*.h`（勾選框）、`module.mk`

## 內容

5×2 個圖示（每格 22×20 遊戲像素），每個圖示呼叫 `Ultima8Engine::handleActionDown/Up`，與按鍵完全相同：

| 圖示 | 功能 | 按鍵 | 圖案 |
|---|---|---|---|
| 背包 | 開啟背包 | I | 物品 529 |
| 人物與屬性 | 屬性頁 | Z | 頭盔 531 第 1 格 |
| 戰鬥模式 | 切換戰鬥 | C | 劍 243 第 68 格（戰鬥中底色變紅） |
| 地圖 | 小地圖 | M | 自繪羊皮紙地圖 |
| 選單 | 遊戲選單 | Esc | 書 613 第 10 格 |
| 鑰匙圈 | 使用鑰匙圈 | K | 物品 79 |
| 召回石 | 使用召回石 | R | 物品 833 |
| 睡袋 | 睡覺 | B | 物品 534 |
| 寫入日記（存檔） | 存檔 | F5 | 書 613 第 2 格（紅） |
| 讀取日記（讀檔） | 讀檔 | F7 | 書 613 第 4 格（藍） |

- 提示：`ui` context 的譯文（`ui/engine.po`，譯名依權威檔：睡袋、召回石）+ 按鍵，以高解析文字顯示。
- 隱藏時 `PointOnGump` 為 false，在右下角點地面照常移動。
- 動作在放開滑鼠時立刻執行（`onMouseClick` 要等雙擊判定，約 0.4 秒延遲）。
- **不寫進存檔**（`FLAG_DONT_SAVE`）：在新遊戲與讀檔完成後才建立，避免占用存檔要還原的物件編號。
- 設定：`quick_bar`（勾選框「Quick action icons (快捷圖示列)」，預設 true）、`quick_bar_autohide`（預設 true；false 則常駐顯示）。在遊戲選項切換時立即建立或關閉。
